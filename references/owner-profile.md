# owner.md — the owner profile

Purpose: stop asking the owner the same question twice, and stop producing work in the wrong style.

Location: `<memory folder>/owner.md` (default `~/.lorekeeper/owner.md`)

---

## Rules for filling this in

1. **Passive first, questions second.** Most entries arrive by noticing: "he always wants tables",
   "she hates emoji", "the answer must be in Chinese".
2. **One question at a time**, and only when it changes the outcome.
3. **Never store secrets** (passwords, keys, card numbers, government IDs) unless the owner asks
   for it in that exact moment — and then say where it is being written.
4. **Mark assumptions**: `(assumed — confirm)`.
5. **Light-touch.** The profile stays under ~100 lines. It is a working summary, not a dossier.
6. **The owner can read, edit or delete it at any time.** Say so when you create it.

---

## Update discipline

- Add an entry the moment it is stated. Do not batch it for later — "later" never comes.
- Prefer a concrete sentence over an abstraction:
  - ✅ "wants a table when comparing three or more options"
  - ❌ "likes clear information"
- If two entries conflict, delete the older one. Never keep both.
- Every entry should be actionable. If you cannot imagine the behaviour it changes, it does not belong here.

---

## Answering "what do you know about me?"

Dump the whole file, plainly, grouped by the headings above. Offer to delete any line.
Never claim to know something that is not in the file.
